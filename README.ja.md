# Eye-Fi OMV

**Bring your old Eye-Fi camera back to life. 📷**

古いデジタルカメラを、もう一度、日常の中へ。

Eye-Fi OMV は、Home Assistant の Eye-Fi 連携をベースに、受信した写真を OpenMediaVault（OMV）TrueNAS 他、などのネットワークストレージへ保存することを目的とした、個人向けの改造版です。

かつて活躍した Eye-Fi カードと、CCD センサーを搭載した古いデジタルカメラ。

そんな、今では使われなくなったり、使い続けるのが難しくなったりした機材を、現代の NAS やスマートホーム環境と組み合わせて、もう一度楽しめないか。

そんな思いから、このプロジェクトを作りました。

## ✨ What is this?

Eye-Fi は、撮影した写真を Wi-Fi 経由で転送できる、少し懐かしいメモリーカードです。

メーカーのサービスが終了した現在、以前のような使い方が難しくなった機材もあります。しかし、ローカルネットワークを活用すれば、今でも楽しめる可能性があります。

このプロジェクトでは、Home Assistant を写真の受信役として使い、ネットワークストレージへ写真を集約することを目指しています。

- 📡 **Eye-Fi の写真を受信** — 対応する Eye-Fi カードから、ローカルネットワーク経由で写真を取り込みます。
- 🗄️ **NAS へ保存** — OpenMediaVault（OMV）など、設定した保存先へ写真を集約します。
- 🧹 **ローカルの一時ファイルを整理** — 保存成功を確認できた場合、Home Assistant 側の元写真と関連する `.log` ファイルを削除するよう改造しています。
- 🏠 **スマートホームとの共存** — Home Assistant を活用することで、写真の受信を現代の自宅ネットワーク環境に組み込めます。

※ 保存先への書き込みに失敗した場合は、再試行のための処理に回され、元ファイルが保持される設計です。ただし、再試行後のファイル整理など、すべての失敗・復旧パターンについて十分な検証ができているわけではありません。

## 📷 Why Eye-Fi again?

最近のカメラにはない魅力が、古いデジタルカメラにはあります。

特に CCD センサーを搭載した機種で撮った写真には、独特の色合いや雰囲気を感じることがあります。もちろん、写りはカメラやレンズ、撮影条件によって異なりますが、そうした古い機材ならではの楽しみは、今でも色あせません。

中古で手に入れた古いカメラや、引き出しに眠っていた Eye-Fi カード。

それらを、写真を撮るたびに手作業で取り込むのではなく、NAS に集約して管理できたら便利です。

**古いカメラで撮る楽しさはそのままに、写真の管理は現代風に。**

それが、このプロジェクトで実現したいことです。

## 🛠️ What has been modified?

このリポジトリは、既存の Eye-Fi Home Assistant 連携をベースにした個人的な改造版です。

主な変更点は次のとおりです。

- OpenMediaVault などのネットワークストレージを利用する環境を想定した説明・構成の整理
- 保存処理の成功・失敗を区別するための処理の改善
- 保存成功後に、Home Assistant のローカル受信フォルダにある元写真と関連 `.log` ファイルを削除する処理
- 保存失敗時や再試行時のログ出力の改善

変更自体は小さなものかもしれません。既存の仕組みがあったからこそ、実現できた改造です。

## ⚠️ Status and limitations

**This is an experimental personal modification.**

この改造版は、実際の Eye-Fi カードと Home Assistant、NAS を使用して動作を確認しています。写真が NAS に保存され、ローカルの受信フォルダに一時ファイルが残らないことを確認しました。

ただし、元のプロジェクトと同等の安定性があることを示す、十分なテストは行えていません。

特に、以下の点には注意してください。

- あらゆる Eye-Fi カードやカメラ、保存先での動作を保証するものではありません。
- ネットワーク障害、保存先の容量不足、権限エラー、再試行時など、すべての状況を検証したわけではありません。
- 再試行キューに入った写真について、後日の保存成功時に元ファイルが自動削除されるとは限りません。
- 保存先への書き込み成功を確認できた場合でも、写真の長期保存やバックアップまで保証するものではありません。

大切な写真を扱う場合は、別途バックアップを確保し、まずは失っても問題のないテスト写真で動作を確認してください。
